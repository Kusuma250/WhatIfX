# WhatIfX — Personal Decision & Outcome Simulator

WhatIfX is a React-based web application that helps users explore possible outcomes of their goals based on their available time, daily effort, and task difficulty.

The application generates best-case, realistic-case, and worst-case scenarios, allowing users to compare different plans and understand how changes in their available hours may affect their estimated outcomes.

## ✨ Features

- **Goal-Based Simulation:** Enter a goal and define the time available to work toward it.
- **Scenario Analysis:** View best-case, realistic-case, and worst-case estimates.
- **Probability Estimates:** See illustrative probability distributions for the generated scenarios.
- **What-If Comparison:** Compare the original plan with an alternative number of working hours.
- **Difficulty Selection:** Choose Easy, Medium, or Hard to adjust the simulation.
- **Visual Results:** Understand scenario differences through a visual bar chart.
- **Simulation History:** Review previous simulations during the current app session.
- **Input Validation:** Receive validation messages for missing or invalid inputs.
- **Responsive Interface:** Use the application on supported desktop and mobile screen sizes.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Kusuma250/WhatIfX.git
   ```

2. Open the project folder:

   ```bash
   cd WhatIfX
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📊 How It Works

1. Enter a goal you want to work toward.
2. Specify the number of days and hours available per day.
3. Select the difficulty level.
4. Optionally enter a different number of hours for a What-If comparison.
5. Click **Simulate** to view the estimated scenarios.
6. Compare the results and review your simulation history.

## 🎯 Purpose

WhatIfX demonstrates how a simple interactive application can help users think through different plans, compare possible outcomes, and make more informed decisions about allocating their time.

## ⚠️ Disclaimer

The scenario values and probabilities are illustrative estimates generated using predefined assumptions. They are not scientifically validated predictions and should not be treated as guarantees of future results.
